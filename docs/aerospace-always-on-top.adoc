// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospace always-on-top [-h|--help] [--window-id <window-id>]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

The overlay uses ScreenCaptureKit and requires Screen Recording permission. Running the command again for the same window removes the overlay.
